# Merke und Male

Gedächtnistraining für Kinder: Bild kurz ansehen, aus dem Gedächtnis nachzeichnen, vergleichen. Ein Merk- und Malspiel ab 3 Jahren — ohne Werbung, ohne In-App-Käufe, komplett offline spielbar.

_A memory game for children: look at a picture, memorize it, draw it from memory, then compare._

## So funktioniert's

1. **Merken** — ein Bild wenige Sekunden ansehen
2. **Zeichnen** — es aus dem Gedächtnis nachmalen
3. **Vergleichen** — Zeichnung und Original übereinanderlegen
4. **Bewerten** — 1 bis 5 Sterne vergeben

## Das steckt drin

- **81 Bilder** in fünf Schwierigkeitsstufen, sortiert nach Themen (Tiere, Fahrzeuge, Natur, Märchen, Essen)
- **Spielvarianten:** nur Umriss merken, gespiegeltes Bild, freies Malen
- **Galerie** für deine Zeichnungen, Teilen als Bild, Zeitraffer des Zeichnens
- **Maskottchen „Mali“**, das mit gesammelten Sternen neue Accessoires bekommt
- **Altersstufen** (3–5 / 6–8 / 9+) mit passender Anzeigedauer und Pinselstärke
- Tägliche Herausforderung, Konfetti und Sounds, Dark Mode, 7 Sprachen
